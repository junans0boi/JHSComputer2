# 자동 견적 후보 자격과 AI 가속기 정책

## 결정

자동 견적 엔진은 가격·재고가 있는 모든 표준 부품을 조합하지 않고, 카테고리별 후보 자격 게이트를 먼저 적용한다. PSU 케이블·커넥터·변환 젠더 같은 액세서리는 PSU 후보에서 제외하고, 고성능 CPU에는 엔트리급 메인보드와 열용량이 부족한 쿨러를 조합하지 않는다. 고전력 GPU는 정격·인증 PSU와 케이스 냉각 조건을 함께 확인한다.

AI 추론 workload가 주된 작업이고 호환 가능한 NVIDIA GPU가 있으면 CUDA 가속이 가능한 NVIDIA 후보를 우선한다. AMD GPU를 NVIDIA 후보와 같은 성능 후보로 섞지 않으며, NVIDIA 후보가 하나도 없을 때만 결과를 완화하거나 `REVIEW_REQUIRED`로 설명한다.

성능 점수는 최소 요구량 충족 여부에서 포화되지 않도록 GPU VRAM·시스템 메모리·CPU 여유분을 연속 점수로 반영한다.

핵심 부품(CPU·GPU·메인보드·RAM·SSD·PSU)과 케이스·쿨러는 제조사·인기 신뢰 신호도 후보 자격과 정렬에 반영한다. 카테고리별 검증 제조사 tier를 우선하고, tier 밖 제조사는 선택된 판매 단위의 후기 수·평점 또는 관리자 승인 같은 충분한 근거가 있을 때만 자동 후보로 허용한다. 스펙 파싱 상태만으로는 제조사·인기 근거를 대체하지 못한다. `POPULARITY_SCORE`는 저장 범위를 리뷰 수로 단정하지 않고 로그 스케일의 보조 점수로만 사용한다. 가격만 낮고 신뢰 근거가 없는 상품은 자동 후보에서 제외한다.

## 배경

실제 운영 결과에서 600W 전원 케이블이 PSU로, 4,690원 45mm 쿨러가 i7-14700용 쿨러로, H610/A620 보드가 16코어 이상 CPU용 보드로 선택됐다. 기존 점수는 최소 요구량을 넘으면 고성능 GPU 사이를 구분하지 못했고, 부품 역할과 제조 생태계 차이를 설명하지 못했다.

## 결과

- 후보가 줄어들 수 있으며, 조건을 만족하는 조합이 없으면 임의의 저가 부품을 넣지 않고 `REVIEW_REQUIRED`를 반환한다.
- AI 후보의 GPU 선택 이유와 CUDA 선호를 결과 설명에 포함한다.
- 후보 결과에 제조사, 후기 수·평점, 신뢰 라벨을 함께 제공해 사용자가 선택 근거를 확인할 수 있게 한다.
- 신뢰 라벨은 `VERIFIED_MANUFACTURER`, `ADMIN_APPROVED`, `POPULAR`, `SPEC_VERIFIED`, `UNVERIFIED`를 구분하며, 관리자 승인이나 스펙 파싱만 된 상품을 검증 제조사처럼 표시하지 않는다.
- 신뢰 점수는 제조사 tier·스펙/관리자 검증·후기 수·평점을 로그 기반으로 합산하며, 가격은 신뢰 근거를 대체하지 않고 가까운 가격대의 tie-breaker로만 사용한다.
- 후기 데이터가 없는 신규 상품을 일괄 금지하지는 않지만, 검증 제조사·관리자 승인 중 어느 근거도 없는 상품은 자동으로 추천하지 않는다. 신뢰 메타데이터 자체가 누락된 카탈로그는 임의 우회하지 않고 `REVIEW_REQUIRED`로 보낸다.
- `POPULARITY_SCORE`는 로그 정규화 점수로 독립적인 인기 근거에 반영하되, 원시값을 리뷰 수와 같은 단위로 비교하지 않는다.
- PSU 인증은 구조화된 `PSU_SPECS.CERTIFICATION` 필드가 `80PLUS` 계열인 경우에만 인정한다. 상품명에 인증 문구가 있어도 스펙 필드가 비어 있으면 자동 후보에서 제외한다.
- `CHIPSET_MAKER`와 상품명에서 NVIDIA/Radeon 신호가 충돌하면 AI CUDA 후보에서 제외한다.
- 이 결정으로 견적 미리보기 규칙 버전은 `quote-preview-v2`로 올린다.
- 크롤러·스펙 데이터가 오염되어도 API 경계에서 조립 불가능한 액세서리와 명백한 역할 오류를 차단한다.
