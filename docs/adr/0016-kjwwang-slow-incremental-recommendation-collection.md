# 견적왕 느린 증분 수집과 최신 추천 스냅샷

작성일: 2026-09-10

## 결정

견적왕 게임별 추천 조합은 한 번에 대량 요청하지 않고, 페이지 단위의 느린 증분
수집기로 운영한다. 수집기는 진행 상태와 조건부 요청 정보를 보존해 중단 후 재개할
수 있으며, 동일한 출처 페이지·게임·해상도·추천 등급·플랫폼·정규화 CPU/GPU 조합은
새 행을 계속 쌓지 않고 최신 관측값으로 갱신한다.

고객에게 공개하는 조합의 식별자는 정규화 CPU 모델과 GPU 모델의 `PublicComboKey`로
한다. 다만 같은 CPU/GPU가 서로 다른 게임·해상도·등급에서 추천될 수 있으므로, 원본
추천 맥락은 `RecommendationContextKey`로 별도 유지한다. 이것은 중복 조합을 화면에
여러 번 보여주는 것과, 실제로 서로 다른 추천 맥락을 잃지 않는 것을 분리한다.

수집 속도는 요청 사이 기본 6초 이상에 작은 무작위 지연을 더하고, 소량의 페이지마다
긴 휴식을 넣는다. 429·5xx·네트워크 오류에는 `Retry-After`를 우선하고 지수 백오프를
적용한다. 오류가 반복되면 해당 페이지에서 멈추고 다음 실행에서 재개한다.

견적왕의 `평균 목표 144FPS`나 해상도별 지원 문구는 추천 기준이지 실제 FPS 측정값이
아니다. 숫자·테스트 시스템·게임 버전·그래픽 조건이 확인된 원문이 없는 한
`GameRecommendationCombo`로만 저장하고 `GameFpsObservation`을 만들지 않는다.

## 이유

- 빠른 전체 크롤링은 차단 가능성과 서비스 부하를 키운다.
- 페이지별 체크포인트와 조건부 요청은 같은 페이지를 반복해서 가져오는 낭비를 줄인다.
- CPU/GPU만으로 합친 공개 조합과 게임별 추천 맥락은 서로 다른 질의를 만족한다.
- 최신 스냅샷을 공개하되 원본 URL과 캡처 시각을 남기면 결과를 재현할 수 있다.

## 범위

- 포함: 견적왕 게임 상세의 게임명·해상도·추천 등급·CPU/GPU·예산·원문 URL
- 포함: 페이지별 체크포인트, 지연·재시도·중단 후 재개, 동일 맥락 최신 갱신
- 제외: 견적왕 추천 문구를 FPS 실측값으로 변환
- 제외: 현재 단계에서 ComputerBase의 모든 GPU/CPU 조합을 자동 생성
