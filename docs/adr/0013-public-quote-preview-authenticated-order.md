# 비로그인 견적 미리보기와 인증 주문 경계

## 상태

Accepted — 2026-09-09

## 결정

조건부 자동 견적 설문과 서버 검증 후보 비교는 비로그인 사용자에게 허용한다. 결과 후보와 장바구니는 먼저 브라우저 임시 저장소에 보관하고, 사용자가 로그인한 뒤에만 서버 견적으로 저장하거나 주문을 접수한다. 인증이 필요한 동작으로 이동할 때는 로그인 또는 회원가입 후 원래 경로로 복귀시킨다.

## 이유

견적 서비스의 핵심 가치는 사용자가 계정 생성 전에 실제 판매 데이터 기반 결과를 확인하는 데 있다. 반대로 서버에 장기간 보관되는 견적과 주문은 고객 식별·주문 상태 추적·가격 재검증이 필요하므로 인증 경계를 유지해야 한다. 이 경계를 화면에 명시하면 사용자가 설문 결과를 잃었다고 오해하거나, 주문 버튼을 눌러서야 로그인 요구를 발견하는 문제를 줄일 수 있다.

## 사용자 규칙

- AI 단독 workload는 게임 목록을 불러오지 못해도 유효한 조건이면 미리보기를 요청할 수 있다.
- 게임 workload는 게임 목록이 준비되고 하나 이상의 유효한 게임을 선택했을 때만 미리보기를 요청한다.
- 예산은 최소 ≤ 목표 ≤ 최대이며 목표 예산은 0보다 커야 한다.
- 비로그인 사용자는 “임시 저장”임을 안내받고, 주문 동작은 “로그인 후 주문”으로 표시한다.

## 영향

- 프론트엔드는 자동 모드에서 수동 부품 카탈로그를 불필요하게 조회하지 않는다.
- 로그인·회원가입의 `next` 경로는 내부 상대 경로만 허용해 안전하게 복귀시킨다.
- 서버의 공개 `POST /api/quotes/preview`와 인증된 저장·주문 API의 책임 경계가 사용자 화면에도 동일하게 드러난다.
