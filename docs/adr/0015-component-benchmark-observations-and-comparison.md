# 표준 부품 벤치마크 관측값과 비교 집합

부품 벤치마크는 `ComponentBenchmarkTest`(이름·버전·점수 지표·대상·단위)와 `ComponentBenchmarkObservation`(한 출처/실측의 원본 점수와 테스트 조건)를 분리해 저장한다. 화면의 `RepresentativeScore`는 동일한 테스트·버전·지표 안에서만 관측값을 요약하며, 서로 다른 Cinebench 버전이나 3DMark 테스트의 점수를 하나의 종합점수로 합치지 않는다. 표준 부품(`parts`)을 비교의 기준으로 삼고 공급처 상품은 출처가 특정 SKU를 보고한 경우에만 보조 연결로 보존한다.

외부 공개값은 `SOURCE_REPORTED`, JHS가 직접 실행한 값은 `MEASURED`로 구분하고, URL·테스트 시스템·드라이버·OS·오버클럭·캡처 시각을 함께 보존한다. 출처 차트가 일부 조건만 공개하면 값을 추정하거나 JHS 실측으로 승격하지 않고, 확인한 값과 `unavailableConditionFields`를 함께 보존해 화면에 부분 조건임을 표시한다. 추천 조합과 게임 FPS 관측값도 분리한다. 숫자와 조건이 확인되지 않은 출처는 추천 조합을 제공할 수는 있어도 FPS 관측값이나 부품 점수를 생성하지 않는다. 이 구조는 출처별 라이선스가 달라져도 원본을 삭제하지 않고 수집 허용 범위만 조절할 수 있게 한다.

## 고려한 선택지

- 모든 벤치마크를 하나의 점수로 합산: 테스트마다 척도와 목적이 달라 비교가 허위로 보일 수 있어 채택하지 않는다.
- 공급처 상품에만 점수를 저장: 동일 부품의 판매처/패키지별 SKU가 갈라지고 표준 부품 간 비교가 어려워 채택하지 않는다.
- 최고 점수만 공개: 냉각·드라이버·오버클럭 차이를 숨기므로 대표 관측 수와 범위를 함께 표시한다.
- 공개 사이트를 무조건 대량 수집: 상업적 재배포 권한과 변경 가능성을 확인할 수 없어, 출처별 허용 범위를 확인한 세로 슬라이스만 채택한다.
