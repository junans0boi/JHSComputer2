# 2026-09 데이터 기반 견적·성능 개선 스펙

## 목표

부품 쇼핑, 자동 견적, 추천 견적, 게임 성능 화면이 같은 컴퓨존 실데이터와 검증된 벤치마크 데이터를 사용하도록 만든다. 첫 화면의 대기 시간은 선택한 카테고리 데이터가 도착하는 즉시 끝나야 하며, 데이터가 없는 경우 임의의 상품명·가격·FPS를 사실처럼 보여주지 않는다.

## 확정 결정

- 부품 쇼핑은 URL의 선택 카테고리(기본 CPU)를 먼저 조회하고 즉시 렌더링한다. 나머지 카테고리는 백그라운드에서 병렬 조회한다. 탭을 바꿨을 때 미수신 카테고리는 해당 카테고리만 기다린다.
- 자동 견적은 `parts` + `supplier_products` + 활성 `supplier_offers` + 최신 `supplier_offer_prices`에서만 상품을 선택한다. 기본 정렬은 컴퓨존 리뷰 수/인기도, 관리자 우선순위, 목표 가격과의 거리, 가격 순서다. 최저가만으로 제조사를 선택하지 않는다.
- 자동 견적은 소켓·메모리·케이스 장착 길이·쿨러 높이·파워 용량을 확인한다. 호환 후보가 없으면 다른 규격을 조용히 끼워 넣지 않고 검토 필요 상태를 표시한다.
- 컴퓨존 전체 재파싱은 기존 `SUMMARY_SPEC_TEXT`로 보강 가능한 문제에 대해 필수가 아니다. 파서는 재수집 시에도 같은 규칙을 사용하고, 별도 repair/validation 스크립트로 기존 행을 보강한다.
- GPU 칩셋과 CPU/메인보드 소켓은 `SUMMARY_SPEC_TEXT`를 기준으로 정규화한다. GPU는 `RX 9070 XT / ...`의 첫 모델 토큰을, CPU/보드는 `소켓1700`, `LGA 1700`을 표준 `LGA1700`으로 저장한다.
- 견적왕 원본 빌드는 조합 수집 데이터로 보존하되, 게임 표의 단일 `평균프레임`과 FHD/QHD/UHD 지원 문구를 해상도별 FPS로 복제하지 않는다. 해상도별 독립 게임 차트를 제공하는 공개 벤치마크 원본만 `SOURCE_REPORTED`로 `benchmark_fps_results`와 API 집계 테이블에 넣고, 없는 해상도는 추정하지 않는다.
- 공개 벤치마크 원본은 테스트 시스템, 원문 URL, 옵션 프리셋, 캡처 시각을 함께 보존한다. 고객 화면에서는 우리 서버가 직접 측정한 값과 외부 매체가 보고한 값을 `MEASURED`와 `SOURCE_REPORTED`로 구분한다.
- 추천 견적은 실제 DB 부품·최신 가격·실제 이미지로 생성한다. 게임 성능은 일괄 하드코딩하지 않고 동일 CPU/GPU 칩셋 조합의 벤치마크 집계에서 연결한다.

## 비목표

- 이번 범위에서 외부 사이트의 모든 게시글을 무단 대량 수집하거나 새로운 벤치마크를 추정 생성하지 않는다.
- 사용자·주문·결제 도메인의 미완성 기능은 변경하지 않는다.
- 브랜드 평판을 주관적으로 판정하는 별도 화이트리스트는 이번 단계에서 도입하지 않는다. 컴퓨존 인기도를 기본 신뢰 신호로 사용하고, 관리자 우선순위로 예외를 통제한다.

## 완료 기준

1. CPU 탭은 다른 7개 카테고리 요청 완료 여부와 무관하게 표시된다.
2. 자동 견적 결과의 모든 상품명/가격/상품번호가 DB의 활성 판매 단위에 존재하고, 호환 실패 결과가 0건이다.
3. 추천 견적 상세에 `recommendation_post_parts`와 `recommendation_post_games`가 존재하며, 화면 금액은 부품 합계+정의된 조립/배송비와 일치한다.
4. `GET /benchmarks/games`, 조합 목록, 조합 상세, 견적 성능 조회가 같은 조합 집계 데이터를 읽는다.
5. 파서 fixture 테스트와 DB validation 결과로 CPU 소켓, GPU 칩셋, 메모리, 케이스/GPU 치수의 누락률을 확인할 수 있다.
6. 변경사항은 typecheck, build, API smoke test, 브라우저의 `/parts`, `/quote`, `/recommendations`, `/benchmarks` 확인을 통과한다.

## 작업 순서

- 데이터 스키마/파서 품질 감사 및 기존 행 repair
- 벤치마크 FPS → combo 집계 동기화
- 선택 카테고리 우선/백그라운드 카탈로그 로더
- DB 기반 호환 자동 견적 엔진
- 실제 부품·벤치마크 기반 추천 견적 생성
- 배포 및 화면 검증 후 각 티켓과 맵 종료
