# 추천 조합 벤치마크 화면 연결

작성일: 2026-09-10
Wayfinder map: #63
관련 API ADR: [ADR-0017](../adr/0017-kjwwang-recommendation-combo-api-boundary.md)
상태: 구현 승인

## 문제

견적왕 추천 맥락을 집계하는 API는 존재하지만 `/benchmarks` 화면은 실제 FPS
조합만 조회한다. 따라서 API에 저장된 추천 조합·게임·해상도·등급 맥락을 사용자가
확인할 수 없다.

## 결정

- 기존 FPS 조합 영역과 별도로 `/benchmarks` 하단에 `추천 조합` 영역을 추가한다.
- FPS 조합과 추천 조합을 하나의 목록이나 하나의 FPS 표로 합치지 않는다.
- 추천 조합 목록의 선택 상태는 `recommendationComboRef` 쿼리 파라미터로 유지한다.
- 최초 진입 시 추천 조합 목록의 첫 항목을 선택하고, 선택한 조합의 상세 맥락을
  게임·해상도·등급·플랫폼·예산·확인 시각 카드로 표시한다.
- 상세는 최신 맥락 120개를 우선 표시하며, 전체 개수와 현재 표시 개수를 함께
  보여줘 일부 표시임을 숨기지 않는다.
- 모바일에서는 표 대신 줄바꿈 가능한 카드 목록을 사용해 긴 게임명·URL·등급이
  화면을 밀어내거나 잘리지 않게 한다.
- 화면에는 FPS 숫자를 표시하지 않는다. FPS는 기존 실제 FPS 영역에서만 표시한다.
- 출처는 API 계약상 보존하되 화면의 제목과 설명은 JHS 용어를 사용하고, 원본
  URL은 각 맥락 카드의 접힌 근거 영역에서만 제공한다.

## 사용자 이야기

- 사용자는 벤치마크 페이지에서 실제 FPS 조합과 추천 조합의 차이를 이해할 수 있다.
- 사용자는 같은 CPU/GPU가 어떤 게임·해상도·등급에서 추천됐는지 확인할 수 있다.
- 사용자는 추천 조합을 선택한 뒤 새로고침하거나 링크를 공유해 같은 상세 상태로
  돌아올 수 있다.
- 사용자는 추천 맥락이 있어도 FPS 측정값이 없다는 사실을 오해하지 않는다.
- 모바일 사용자는 긴 모델명·게임명·원본 URL 때문에 콘텐츠가 잘리지 않는다.

## 구현 결정

- 프론트 서버 로더에 `RecommendationCombo`와 `RecommendationContext` 타입을 추가한다.
- `loadRecommendationCombos()`는 `/benchmarks/recommendation-combos`를 호출하고,
  `loadRecommendationComboDetail()`은 선택된 `publicComboRef`를 호출한다.
- 서버 컴포넌트인 `/benchmarks`가 두 데이터를 로드하고, 전용 프레젠테이션
  컴포넌트에 전달한다.
- API 장애나 빈 결과는 기존 벤치마크 화면을 깨뜨리지 않고 추천 영역 안에서만
  안내하며, 장애와 정상적인 빈 결과를 구분한다.
- 외부 근거 링크는 `http`/`https`만 허용하고 카드의 접힌 근거 영역에서만
  노출한다.

## 테스트 결정

- 타입체크와 production build를 통과한다.
- 로더의 API 경로·fallback 타입이 컴파일되는지 확인한다.
- 브라우저 smoke에서 추천 목록 선택, URL 쿼리 유지, 상세 맥락 표시를 확인한다.
- 좁은 모바일 폭에서 카드의 긴 텍스트와 원본 URL이 잘리지 않는지 확인한다.

## 범위 밖

- 추천 맥락을 실제 FPS 데이터로 변환하거나 FPS를 추정하는 기능
- `/recommendations` 게시글의 콘텐츠 모델 변경
- API의 출처·집계 규칙 변경
- 추천 조합별 자동 견적 생성·주문 연결
