## 2. 문제점 — 표면이 아닌 구조적 원인

### 문제 1. 콘텐츠 공급이 사실상 중단됐다

2026년 8개월 동안 영상 3개 — 월 0.4개. 유튜브 알고리즘은 꾸준히 올리는 채널에게 노출을 준다. 업로드가 없으면 기존 구독자에게도 사라진다. 신규 고객 유입 경로가 막힌 상태에서 주문 건수 감소는 필연적 결과다.

### 문제 2. 콘텐츠 방향과 시청자 니즈가 엇갈렸다

채널 인기 영상 TOP 5는 전부 3만~10만원 초저가 조립 콘텐츠다 (7년 전 영상들, 조회수 10만+). 그런데 최근 영상은 150만~600만원짜리 고가 견적 중심으로 바뀌었다. 채널을 찾아오는 시청자가 기대하는 것과 올라오는 내용이 달라지면 이탈이 생기고 신규 유입도 줄어든다.

### 문제 3. 경쟁사 대비 신뢰도 자산이 없다

마인드피씨(6.6만 구독), 벡스컴(5.4만 구독)은 매월 실측 FPS 수치·가격 변동 분석을 4K 영상으로 제공한다. 시청자는 "이 견적으로 내 게임이 몇 FPS 나오는지"가 궁금한데, 정효성TV는 이 데이터를 보여주지 않는다. 신뢰 근거가 없으면 견적 문의로 이어지지 않는다.

### 문제 4. 사업이 1인 집중 구조라 지속이 불가능하다

대표 혼자 촬영·나레이션·주문·조립·배송을 담당한다. 육아가 겹치자 사업 전체가 멈췄다. 영상 제작, 고객 응대, 데이터 관리 중 어느 하나라도 자동화하거나 분업하지 않으면 이 구조는 반복될 수밖에 없다.

### 문제 5. 웹 플랫폼 없이 유튜브 하나에만 의존한다

경쟁사들은 자체 쇼핑몰과 연동해 영상에서 바로 구매로 이어지게 만든다. 정효성TV는 영상을 보고 관심 생긴 시청자가 카카오톡으로 따로 연락해야 한다. 이 마찰이 전환을 가로막는다.

## 4. 성장 전략 — 단계별 로드맵

### Phase 1. 즉시 (1개월) — 영상 공급 재개

- [ ] Claude AI로 스크립트 초안 작성 → 대표 검수 → 나레이션 → 편집 파이프라인 구성
- [ ] Shorts 3개 선행 제작 (기존 인기 영상 클립 재편집, 30초 견적 요약)
- [ ] "이달의 견적 추천" 고정 포맷 첫 영상 출시
- [ ] 업로드 주기 캘린더 고정 (예: 매주 화요일)

> 알고리즘은 꾸준함을 보상한다. 지금 당장 필요한 건 "있다는 신호"를 채널에 다시 보내는 것이다.

### Phase 2. 단기 (1~3개월) — 데이터 기반 신뢰도 구축

- [ ] CPU+GPU 조합별 주요 게임 FPS 데이터 자동 수집·정리 (Agent 파이프라인 활용)
- [ ] "○○만원 견적으로 ○○ 게임 몇 FPS?" 포맷 시리즈 론칭
- [ ] 영상 내 벤치마크 그래픽 삽입으로 시각적 신뢰 강화
- [ ] 가격 변동 뉴스 + 현재 최적 견적 연계 콘텐츠

### Phase 3. 중기 (3~6개월) — 웹 플랫폼 론칭

- [ ] JHSComputer2 MVP 배포 (견적 생성 + 주문 접수 + 상태 추적)
- [ ] 영상 설명란에 해당 견적 직접 링크 삽입
- [ ] 추천 견적 페이지를 유튜브 쇼핑 탭과 연결
- [ ] 주문 단가 상승 추세(평균 240만원)에 맞춰 프리미엄 패키지 확대

### Phase 4. 장기 (6개월~) — 수익 다각화

- [ ] 유튜브 수익화 요건 충족 시 광고 수익 발생
- [ ] 부품사 협찬·체험단 협업 (구독자 증가에 따라)
- [ ] 데이터 기반 견적 추천 페이지를 B2C 신뢰 자산으로 활용
- [ ] 업그레이드 상담, A/S 패키지 등 부가 서비스 구조화

## 5. AI 활용 전략 — 1인 사업의 한계를 넘는 법

| 영역 | 활용 방법 | 기대 효과 |
|---|---|---|
| 스크립트 작성 | 부품 구성·예산 입력 → Claude가 초안 생성 → 대표 검수 | 영상 준비 시간 60% 단축 |
| FPS 데이터 수집 | Agent가 견적왕·왕가PC에서 조합별 FPS 자동 수집 | 직접 측정 없이 신뢰 데이터 삽입 |
| 썸네일 설계 | AI가 제목·키워드 분석 → 텍스트·레이아웃 제안 | CTR 개선으로 기존 영상 조회수 회복 |
| 가격 모니터링 | 다나와·컴퓨존 가격 변동 감지 → 콘텐츠 주제 자동 제안 | 시장 타이밍에 맞는 영상 |
| 댓글 응대 | 자주 나오는 질문 유형 분류 → 표준 답변 반자동 | 응답 시간 단축 + 고객 신뢰 유지 |
| 견적 자동 추천 | 웹에서 예산·용도·게임 입력 → 최적 조합 자동 생성 | 24시간 견적 제공, 카카오 문의 마찰 제거 |

## 6. 이준환의 제안 — 관계 구조를 다시 설계하자

### 현재 구조의 문제

영상 건당 5만원 구조 → 업로드가 없으면 수입이 없음. 저 역시 이 구조에서 사업 성장에 적극적으로 투자하기 어렵다. 2019년부터 함께했는데 지금 이 상태를 방치하는 건 함께에 대한 예의가 아니라고 생각한다.

### 제가 할 수 있는 것

영상 기획·편집 + JHSComputer2 플랫폼 개발 + AI 파이프라인 구축 + 데이터 기반 콘텐츠 설계. 기술 파트너로 역할을 확장할 의향이 있다.

### 제안 수익 구조

**옵션 A. 월정액 방식** (영상 4개 이상 기준)
→ 예측 가능한 수입, 꾸준한 업로드 인센티브

**옵션 B. 플랫폼 주문 매출 연동**
→ 성장할수록 함께 성장하는 구조

구체 금액은 대표와 협의하되, 지금 구조를 유지하는 것은 저에게도 대표에게도 손해다.

### 대표에게 필요한 것

- 주 1회 나레이션 녹음 (30분~1시간)
- 월 1회 조립·테스트 영상 촬영

**나머지는 제가 AI와 함께 처리한다.** 지금처럼 혼자 모든 것을 짊어지지 않아도 된다.

### 첫 번째 공동 목표

> **3개월 안에 구독자 1만 돌파**
>
> 이것만 달성해도 유튜브 수익화, 신규 주문 유입, 플랫폼 신뢰도가 동시에 올라간다.
