## 1. 사업 진단 — 핵심 수치

| 지표 | 수치 |
|------|------|
| 연간 주문 수 | 149건(2020) → 17건(2024), **-89%** |
| 평균 단가 | 96.5만 → 240만원, **+149%** |
| 실질 월수익 추정 | 조립비 8만 × ~2건 = **약 17만원/월** |
| YouTube 구독자 | 1,065명 (최근 업로드 거의 없음) |

**진단:** YouTube 업로드 중단 → 고객 유입 차단. 단가는 올랐지만 주문량 붕괴. 지금 구조로는 자연 회복 불가. 채널 재건 + 자동 주문 플랫폼 동시 진행 필요.

## 2. 전략 방향 — 확정 결정 목록

### 사업 모델
- AI+TTS 영상으로 유입 → JHSComputer2 자동 주문 플랫폼으로 전환
- 효성이형: **조립+배송만** 담당
- 이준환: 개발·콘텐츠·운영 (프리랜서 + 구두 합의 운영자)

### 영상 형식
- 얼굴·목소리 없음
- 차분한 남성 AI TTS
- 부품 이미지 + 가격 화면 + FPS 데이터 기반

### 콘텐츠 방향
- 데이터 기반 + 실용 가이드 혼합
- 주제: 부품 이슈 / 월간 견적 추천 / 게임별 FPS 성능

### 업로드 주기
- 본영상 주 1회 + 쇼츠 주 2~3개

### 플랫폼 제안 방식
- 웹서비스 데모 + 시험 영상을 함께 효성이형에게 제시

### 주문 알림
- Discord 봇. 효성이형이 이미 쓰는 채널에 주문 알림 자동 전송.

### 이준환 법적 지위
- 취업 중 → 공동사업자 불가
- **프리랜서 계약 + 구두 합의 운영자**

### 미결 (나중에)
- 브랜드명: 웹서비스·채널 방향 확정 후 결정
- 수익 구조: 성과 나온 후 합의

## 4. 콘텐츠 파이프라인

### 툴 스택

| 도구 | 역할 | 비용 |
|------|------|------|
| **Vrew** | 스크립트 → TTS → 자막 → 초안 편집 | 무료 / ₩9,900/월 |
| **Final Cut Pro** | 색보정 · 타이틀 · 마무리 편집 | 이미 보유 |
| **CapCut** | 쇼츠 세로 포맷 변환 + AI 자막 | 무료 |

### 주간 제작 흐름 (주 10시간 기준)

```
스크립트 작성 (2h)
  → Vrew: TTS + 자막 + 초안 (2h)
  → 화면 녹화: 가격/FPS/부품 화면 (1h)
  → Final Cut: 색보정 + 마무리 (2h)
  → CapCut: 쇼츠 1~2개 (1h)
총 ~8~9h → 주 10시간 예산 내 가능
```

### 데이터 소스
- **국내 가격**: JHSComputer_Agent 자동 수집 (견적왕·왕가PC)
- **FPS·벤치마크**: Gamers Nexus / TechPowerUp 공개 데이터 참조

## 5. 실행 계획 — A. 웹서비스 먼저

### Phase 1 — 웹서비스 블로커 4개 해결 (지금 → 2~3주)
> Claude Code 주도

- DB 연결 (Docker / 서버 #3)
- 견적→주문→추적 E2E 플로우 서버 연결
- 비밀번호 bcrypt 적용
- Discord 봇 생성 + 주문 알림 웹훅
- 모바일 반응형 QA + 관리자 권한 가드

### Phase 2 — 효성이형 시연 + 합의
- 실제 기동 가능한 웹서비스 시연
- 사업 진단 수치 제시 (17만원/월 현실 → 자동화 가능성)
- 역할 분담 합의

### Phase 3 — 콘텐츠 파이프라인 시작
- Vrew 세팅 + 첫 시험 영상 1개 제작
- YouTube 채널 정비 + 업로드 시작
- Agent 자동 수집 정기 실행 설정

### Phase 4 — 동시 운영 체제
- 주 1회 본영상 + 주 2~3회 쇼츠 정기 업로드
- 유입 → JHSComputer2 주문 전환 확인
- 수익 구조 합의 (성과 기반)
- 브랜드명 + 채널 리브랜딩 결정
